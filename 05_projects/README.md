# 🧮 Calculator App

## 📖 Description
A simple calculator built using JavaScript that performs basic arithmetic operations.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus (%)
- Invalid operator handling
- Division by zero handling

## 🛠️ Technologies Used
- JavaScript

## 📚 Concepts Used
- Variables
- Operators
- if-else if
- Comparison Operators
- console.log()

## ▶️ How to Run
1. Open the project in VS Code.
2. Open Terminal.
3. Run:
   node calculator.js
